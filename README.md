# 云大工作台

面向云南大学的 macOS 工作台，包含每周课表、待办事项、校内资源和校园 VPN。独立项目，发布包适用于 Apple 芯片 Mac，最低 macOS 13。

## 使用

- 解压 ZIP，将「云大工作台.app」移入「应用程序」。
- 校内可以直接打开常用链接。需要校园 VPN 时，点「校内资源」里的「校园 VPN」一整行展开。若 App 提示缺少路由组件，再运行安装包中的 `install-helper.command`。该脚本要求管理员授权，用于创建 VPN 虚拟网卡和分流。
- 可在设置中添加自己的校内设备 IP。校园网段仅在网关授权时启用。
- 课表和设备同步需要能访问学校页面，并保持对应的网页登录有效。浏览器读取还取决于 macOS 自动化和浏览器设置。自动同步目前仍有兼容性问题。

## 构建

在 Apple 芯片 Mac 上安装 Xcode Command Line Tools，然后运行 `bash build.sh`。ZIP 输出到 `build/`。构建使用临时目录，应用为本地临时签名。
